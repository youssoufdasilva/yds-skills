# Triage labels

The engineering skills use five canonical triage roles. This file maps those roles to the strings stored in local issue files.

| Canonical role      | Local status          | Meaning                                  |
| ------------------- | --------------------- | ---------------------------------------- |
| `needs-triage`      | `needs-triage`        | A maintainer needs to evaluate the issue |
| `needs-info`        | `needs-info`          | Waiting for more information             |
| `ready-for-agent`   | `ready-for-agent`     | Fully specified and ready for an agent   |
| `ready-for-human`   | `ready-for-human`     | Requires human implementation            |
| `wontfix`           | `wontfix`             | Will not be implemented                  |

When a skill names a triage role, use the corresponding local status from this table.
